A [make.fun](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270) entry: one sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

## The tip

> Tip: your coding agent read 10,000 lines to change one. Be kind — it did the onboarding you skipped.

100 characters, one line. The agent did the thankless reading; the developer skipped the onboarding. Both of them feel seen.

## How it works

`main.ts` (Node 22) writes the tip to `/output/entry.txt`, with a guard that it stays within 1–200 characters on a single line:

```sh
node main.ts
cat /output/entry.txt
```
